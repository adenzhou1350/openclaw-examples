# AI Writer - AI 写作助手

帮助用户快速生成各类文案，提升内容创作效率。

## 功能

- 📝 小红书笔记生成：根据主题生成吸引人的小红书文案
- 🏷️ 闲鱼商品描述：生成高效的闲鱼商品发布文案
- 📄 简历优化：帮助优化简历内容和格式
- 📣 营销文案：生成吸引人的营销推广文案
- 📝 自我介绍：生成个人简介/介绍文案

## 使用方法

在对话中直接调用：

```
帮我写一篇小红书笔记，主题是：OpenClaw 部署教程
```

```
帮我写一个闲鱼商品描述，关于：Python 代码代写服务
```

## 配置

无需额外配置，使用内置大语言模型生成内容。
