# ⏰ Reminder Skill - 定时提醒

> 设置定时提醒，支持一次性提醒和周期性提醒

## 功能特性

- ⏱️ **一次性提醒** - 指定时间提醒一次
- 🔄 **周期性提醒** - 每天/每周定时提醒
- 💧 **健康提醒** - 喝水、运动、护眼提醒预设
- 📱 **多通道推送** - 支持钉钉/微信/Telegram 推送

## 快速开始

### 1. 配置提醒

编辑 `reminder.sh`，设置提醒时间：

```bash
# 每天早上9点提醒
CRON_TIME="0 9 * * *"
MESSAGE="☀️ 早上好！新的一天开始了"

# 每小时喝水提醒
CRON_TIME="0 * * * *"
MESSAGE="💧 该喝水了！"
```

### 2. 添加 cron 任务

```bash
# 添加到 crontab
crontab -e
# 添加: 0 9 * * * /path/to/reminder.sh
```

## 使用示例

### 一次性提醒

```bash
# 20分钟后提醒
at now + 20 minutes -f reminder.sh
```

### 周期性提醒

| 提醒类型 | Cron 表达式 | 说明 |
|---------|-------------|------|
| 每天早上9点 | `0 9 * * *` | 早安提醒 |
| 每小时 | `0 * * * *` | 整点提醒 |
| 每周一 | `0 9 * * 1` | 周一提醒 |
| 每天下午2点 | `0 14 * * *` | 下午提醒 |

## 环境变量

| 变量 | 说明 | 示例 |
|-----|------|------|
| REMINDER_MESSAGE | 提醒内容 | "喝水啦！" |
| REMINDER_WEBHOOK | 钉钉/飞书 Webhook | https://oapi.dingtalk.com/... |
| REMINDER_TYPE | 提醒类型 | one-time / recurring |
