# SEO Optimizer - SEO 优化助手

为小红书、闲鱼等内容平台优化关键词和标签，提升内容曝光率。

## 功能

- 🔍 **关键词分析**：分析内容相关的高热度关键词
- 🏷️ **标签推荐**：推荐适合的热门标签
- 📝 **标题优化**：生成 SEO 友好的标题
- 📊 **内容评分**：评估内容的 SEO 表现

## 使用方法

在对话中直接调用：

```
优化这篇笔记的 SEO：小红书内容...
```

```
给我推荐一些关于 Python 学习的标签
```

## 示例

### 标签推荐

输入：`Python 编程入门`

输出：
> 推荐标签：
> - #Python #编程入门 #教程 #学习 #技能
> - #零基础学编程 #Python教程 #编程学习
> - #兼职 #技能变现 #副业

### 标题优化

输入：`教你用 OpenClaw`

输出：
> **优化后标题**：
> - 姐妹必看！用 OpenClaw 打造专属 AI 助手🚀
> - 手把手教你用 OpenClaw 做自己的助手🤖
> - OpenClaw 部署教程｜小白也能学会

## 平台支持

- 小红书
- 闲鱼
- 知乎
- 抖音/B站 标题

- 内容发布前优化
