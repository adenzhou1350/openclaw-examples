# ⭐ Horoscope Skill

每日星座运势查询，支持 12 星座。

## 功能

- 查询今日/明日运势
- 包含事业、爱情、财运、健康指数
- 幸运数字和幸运色

## 使用方法

```bash
# 安装依赖
pip install requests beautifulsoup4

# 使用示例
python scripts/horoscope.py 白羊
```

## 支持星座

白羊座、金牛座、双子座、巨蟹座、狮子座、处女座、
天秤座、天蝎座、射手座、摩羯座、水瓶座、双鱼座

## 自动化

配合 cron 可实现每日定时推送：

```bash
# 每天早上8点发送运势
0 8 * * * /path/to/horoscope.sh 射手座 >> ~/horoscope.log
```
