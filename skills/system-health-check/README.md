# 🏥 System Health Check Skill

系统健康检查工具，监控服务器关键指标并生成健康报告。

## 功能特性

- ✅ CPU 使用率监控
- ✅ 内存使用情况
- ✅ 磁盘空间检测
- ✅ 进程状态分析
- ✅ 服务健康检查
- ✅ 历史趋势记录

## 使用方法

```bash
# 运行健康检查
./health_check.sh

# 检查特定指标
./health_check.sh --cpu
./health_check.sh --memory
./health_check.sh --disk

# 静默模式（仅返回状态码）
./health_check.sh --quiet

# 帮助
./health_check.sh --help
```

## 集成 Cron

```bash
# 每天早上 8 点自动检查
0 8 * * * /path/to/health_check.sh --quiet >> /var/log/health.log 2>&1
```

## 报警阈值（可配置）

| 指标 | 警告 | 严重 |
|------|------|------|
| CPU | > 70% | > 90% |
| 内存 | > 80% | > 95% |
| 磁盘 | > 75% | > 90% |

## 依赖

- bash 4.0+
- coreutils (df, free, top)
- cron (可选，用于定时任务)
